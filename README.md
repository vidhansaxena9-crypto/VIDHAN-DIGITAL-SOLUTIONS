# Vidhan Digital Solution

A professional one-page business website with a Node.js backend and SQLite database.

## Features
- Modern landing page with sections for services, industries, about, and contact
- Real contact form submission handling
- SQLite database for storing consultation requests
- Ready for deployment on Render, Railway, or any Node host

## Run locally
```bash
npm install
npm start
```
Open http://localhost:3000

## API endpoints
- GET /api/health
- POST /api/contact
- GET /api/messages

## Deploy
Use Render with the included render.yaml file or set the start command to `npm start`.
